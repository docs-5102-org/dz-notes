# 常用 JavaScript/Node.js 工具库总结

## 📦 UUID/ID 生成库

| 库名称 | 大小 | 周下载量 | 特点 | 使用场景 | 安装命令 |
|--------|------|----------|------|----------|----------|
| **uuid** | ~5KB | 50M+ | 标准 UUID 格式，支持 v1/v3/v4/v5 | 需要标准 UUID，兼容现有系统 | `npm install uuid` |
| **nanoid** | ~130B | 20M+ | 超小体积，URL 友好，比 UUID 快 60% | 前端应用，短链接，体积敏感场景 | `npm install nanoid` |
| **ulid** | ~2KB | 5M+ | 可按时间排序，26 字符固定长度 | 数据库主键，需要排序的场景 | `npm install ulid` |
| **cuid2** | ~3KB | 1M+ | 防碰撞设计，可排序，分布式友好 | 高并发，分布式系统 | `npm install @paralleldrive/cuid2` |

## 🎯 推荐组合方案

### 🌟 现代前端项目标配

```bash
# 核心工具
npm install nanoid date-fns axios

# React 项目
npm install react-hook-form zod zustand
npm install @tanstack/react-query

# TypeScript
npm install -D typescript @types/node

# 开发工具
npm install -D vite vitest
```

### 🏢 企业级应用

```bash
# 工具库
npm install lodash-es uuid dayjs

# UI 框架
npm install antd

# 状态管理
npm install redux @reduxjs/toolkit

# HTTP 请求
npm install axios

# 表单处理
npm install react-hook-form yup
```

### ⚡ 性能优先小型项目

```bash
# 最小工具集
npm install nanoid dayjs ky

# 无需大型 UI 框架
npm install shadcn/ui  # 按需复制组件

# 状态管理
npm install zustand

# 表单
npm install react-hook-form zod
```

## 📈 选择建议

| 需求 | 推荐库 | 理由 |
|------|--------|------|
| **生成唯一 ID** | nanoid | 体积最小，性能最好 |
| **工具函数** | radash (新项目) / lodash (老项目) | 现代化 vs 稳定性 |
| **日期处理** | date-fns | 体积小，Tree-shaking 友好 |
| **HTTP 请求** | axios | 功能完整，生态成熟 |
| **状态管理** | zustand | 简单易用，零样板 |
| **表单处理** | react-hook-form + zod | 性能好，类型安全 |
| **UI 组件** | Ant Design (企业) / shadcn/ui (灵活) | 按需选择 |
| **Markdown 渲染** | @uiw/react-markdown-preview | 开箱即用 |

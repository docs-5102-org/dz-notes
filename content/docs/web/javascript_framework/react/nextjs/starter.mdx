# Next.js 教程

Next.js 是基于 React 的全栈框架，由 Vercel 维护，适合构建内容站、后台系统、企业应用和 SaaS 产品。它提供文件路由、服务端渲染、静态生成、API 路由和构建优化等能力。

## Next.js 的主要特性

### 混合渲染模式

Next.js 支持多种渲染方式：

- `SSG`：构建时生成静态页面
- `SSR`：请求时在服务端渲染
- `CSR`：在浏览器中完成交互式渲染

### 文件系统路由

通过 `app` 或 `pages` 目录自动生成路由，无需额外手写基础路由配置。

### API 路由

可以直接在项目中编写接口逻辑，便于构建全栈应用。

### 自动代码拆分

每个页面只加载自身所需代码，减少首屏开销。

### 内置优化

- 图片优化
- 字体优化
- Script 加载优化
- 更好的构建与缓存策略

### TypeScript 支持

Next.js 原生支持 TypeScript，适合中大型项目开发。

### 国际化支持

适合构建多语言站点或区域化内容系统。

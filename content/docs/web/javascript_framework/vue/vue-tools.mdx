# Vue 工具生态

这里整理 Vue 项目中常见的二维码、调试、移动端适配、手势、滚动、复制、阅读器与导航类工具，方便按场景快速选型。

## 二维码

### `vue-qr`

- 官网：[https://www.npmjs.com/package/vue-qr](https://www.npmjs.com/package/vue-qr)
- 场景：生成二维码，并支持中间插入 logo

安装：

```bash
npm install vue-qr --save
```

示例：

```vue
<template>
  <vue-qr :logo-src="imageUrl" text="https://example.com" :size="200" />
</template>

<script>
import vueQr from 'vue-qr';

export default {
  name: 'QrcodeDemo',
  components: {
    vueQr,
  },
  data() {
    return {
      imageUrl: require('./assets/logo.png'),
    };
  },
};
</script>
```

### `qrcodejs2`

- 官网：[https://www.npmjs.com/package/qrcodejs2](https://www.npmjs.com/package/qrcodejs2)
- 场景：在容器节点中动态渲染二维码

安装：

```bash
npm install --save qrcodejs2
```

示例：

```vue
<template>
  <div class="qrcode" ref="qrCodeUrl"></div>
</template>

<script>
import QRCode from 'qrcodejs2';

export default {
  mounted() {
    this.createQrCode();
  },
  methods: {
    createQrCode() {
      new QRCode(this.$refs.qrCodeUrl, {
        text: 'https://example.com',
        width: 100,
        height: 100,
        colorDark: '#000000',
        colorLight: '#ffffff',
        correctLevel: QRCode.CorrectLevel.H,
      });
    },
  },
};
</script>
```

## 移动端适配

### `lib-flexible`

`lib-flexible` 是较早期的移动端适配方案，核心思路是根据 `viewport` 和 `dpr` 动态设置根字号，再通过 `rem` 做布局缩放。

官方资源：

- GitHub：[https://github.com/amfe/lib-flexible](https://github.com/amfe/lib-flexible)
- NPM：[https://www.npmjs.com/package/lib-flexible](https://www.npmjs.com/package/lib-flexible)

引入方式：

```html
<script src="https://cdn.bootcdn.net/ajax/libs/lib-flexible/0.3.2/flexible.min.js"></script>
```

说明：

- 旧项目仍可参考
- 新项目更建议使用 `postcss-pxtorem`、`viewport` 或框架自带方案

## 手势工具

### Vue 3 常见选型

| 工具 | 适用环境 | 特点 |
| --- | --- | --- |
| `vue3-touch-events` | Vue 3 | 支持 `tap`、`swipe`、`touch`、`hold` 等常用事件 |
| `vue3-touch-hammer` | Vue 3 + Hammer.js | 基于 Hammer.js，适合更复杂的手势识别 |
| `vue3-hand-mobile` | Vue 2 / Vue 3 | 轻量，支持 `v-touch:*` 指令 |
| `Hammer.js` | 通用 | 底层手势库，支持 `pan`、`swipe`、`pinch`、`rotate` |

参考：

- [vue3-touch-events](https://www.npmjs.com/package/vue3-touch-events)
- [vue3-touch-hammer](https://github.com/maryasov/vue3-touch-hammer)
- [vue3-hand-mobile](https://www.npmjs.com/package/vue3-hand-mobile)
- [Hammer.js](https://hammerjs.github.io/)

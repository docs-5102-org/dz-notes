### zTree工具

zTree 是一个基于 jQuery 的树形插件，常用于组织结构、权限树、菜单树等功能。

---

#### 📌 zTree 官方资源

* **官网**：
  👉 [https://github.com/zTree/zTree_v3](https://github.com/zTree/zTree_v3)


---

⚠️ **注意**：

* zTree 已经多年不再活跃更新，现在多用于 **老项目**。
* 新项目建议使用现代框架的替代方案，例如：

  * Vue：`element-plus` 的 `<el-tree>`、`ant-design-vue` 的 `Tree`。
  * React：`antd` 的 `Tree`、`react-arborist`。

# 什么是umask？

umask 的作用是限制新建文件或目录的默认权限。

## **umask 权限计算原理表**

### 1. 最大默认权限

| 类型 | 最大默认权限（八进制） | 最大默认权限（符号）  |
| -- | ----------- | ----------- |
| 文件 | `666`       | `rw-rw-rw-` |
| 目录 | `777`       | `rwxrwxrwx` |

> ⚠ 文件默认不会给 `x`（执行）权限，因为系统无法假设你创建的是可执行文件。

---

### 2. 计算公式

```
新权限 = 最大默认权限 - umask
```

减法是按**位**计算（八进制每一位分别相减）。

---

### 3. 常见 umask 对照表

| umask | 文件权限(八进制) | 文件权限(符号)  | 目录权限(八进制) | 目录权限(符号)  |
| ----- | --------- | --------- | --------- | --------- |
| 000   | 666       | rw-rw-rw- | 777       | rwxrwxrwx |
| 002   | 664       | rw-rw-r-- | 775       | rwxrwxr-x |
| 022   | 644       | rw-r--r-- | 755       | rwxr-xr-x |
| 027   | 640       | rw-r----- | 750       | rwxr-x--- |
| 077   | 600       | rw------- | 700       | rwx------ |

---

### 4. 图解计算（以 umask=002 为例）

**文件：**

```
最大权限：  6  6  6    (rw-rw-rw-)
umask：     0  0  2    (----- -w- -w-)
结果：      6  6  4    (rw-rw-r--)
```

**目录：**

```
最大权限：  7  7  7    (rwxrwxrwx)
umask：     0  0  2    (----- -w- -w-)
结果：      7  7  5    (rwxrwxr-x)
```

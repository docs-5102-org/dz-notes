# Gitea

Gitea 是轻量级的自建 Git 服务与 DevOps 平台，提供仓库管理、代码评审、Issue、软件包和 Gitea Actions 等功能。

## 内容范围

- Gitea 服务配置、用户注册和仓库访问控制
- SSH 密钥生成、授权与多账号访问
- Gitea Actions 工作流、Act Runner 配置和镜像映射
- Runner 缓存、插件选择和常见自动化实践

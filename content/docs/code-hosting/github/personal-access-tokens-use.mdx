# GitHub Personal Access Token

GitHub 已不再支持使用账户密码进行 Git HTTPS 操作，可以使用 Personal Access Token（PAT）完成身份验证。

## 创建访问令牌

1. 登录 GitHub，打开 [Developer settings](https://github.com/settings/tokens)。
2. 根据需要选择 **Fine-grained tokens** 或经典 Token。
3. 设置名称、过期时间和最小必要权限。
4. 创建后立即保存令牌。GitHub 通常只显示一次令牌内容。

## 使用 HTTPS 克隆

建议直接使用普通 HTTPS 地址，在提示输入密码时粘贴 Token，不要把 Token 写入远程 URL：

```bash
git clone https://github.com/OWNER/REPOSITORY.git
```

- 用户名：GitHub 用户名。
- 密码：Personal Access Token。

## 在自动化环境中使用

将令牌保存到 GitHub Actions Secrets 或本地环境变量中，不要写入仓库文件：

```bash
$env:GITHUB_TOKEN = "<GITHUB_TOKEN>"
git clone https://oauth2:${GITHUB_TOKEN}@github.com/OWNER/REPOSITORY.git
```

GitHub Actions 中优先使用平台自动提供的 `GITHUB_TOKEN`，并为工作流设置最小权限：

```yaml
permissions:
  contents: read
```

## 安全注意事项

- 不要在 Markdown、脚本、远程 URL 或提交历史中保存真实 Token。
- 不要把 Token 分享到截图、聊天记录或日志中。
- 发现 Token 泄露后，应立即在 GitHub 设置中撤销并重新生成。
- Token 权限和有效期应遵循最小权限、短有效期原则。

# GitHub 使用规则与费用

## 私有仓库

个人账户的私有仓库数量和协作者限制可能随政策调整，请以[仓库可见性官方文档](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/setting-repository-visibility)为准。

## GitHub Codespaces 计费说明

- 免费额度和超限费用以当前账户和地区政策为准。当前是（个人账户每月免费 60 小时（2 核） + 15GB 存储 **6** ）
- **超限费用**：计算时间按核心数计费（如 2 核 0.18/小时），存储0.07/GB/月 **6** 。
- 详细计费规则请参考 [GitHub Codespaces 计费文档](https://docs.github.com/en/billing/managing-billing-for-your-products/managing-billing-for-github-codespaces/about-billing-for-github-codespaces)。


## 停止 Codespaces

访问 [GitHub Codespaces](https://github.com/codespaces)，在工作空间右侧菜单中选择 **Stop codespace**。

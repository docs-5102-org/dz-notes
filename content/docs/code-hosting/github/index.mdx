# GitHub

GitHub 是基于 Git 的代码托管和开源协作平台，支持仓库、Issue、Pull Request、Actions 等功能。

## 内容范围

- 仓库创建、分支管理和 Pull Request
- SSH 密钥、Fine-grained token 与权限控制
- Issue、Project 和团队协作
- GitHub Actions、Pages 与自动化部署
- 开源许可证、贡献规范和安全配置

请将访问令牌、私钥和其他敏感信息保存到本地安全存储或平台 Secrets 中，不要提交到公开仓库。

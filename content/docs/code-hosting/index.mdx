# 代码托管

这里整理 Git 版本控制，以及 Gitee、Gitea、GitHub 等代码托管平台的使用、协作和发布实践。

## 子目录

- [Git](/docs/code-hosting/git)
- [Gitee](/docs/code-hosting/gitee)
- [GitHub](/docs/code-hosting/github)
- [Gitea](/docs/code-hosting/gitea)

## 使用建议

1. 使用 Git 管理本地版本和分支，提交信息保持清晰、可追踪。
2. 将远程仓库作为协作和备份入口，按项目需要选择 Gitee、Gitea 或 GitHub。
3. 不要把访问令牌、私钥、云服务密钥和其他敏感配置提交到仓库。

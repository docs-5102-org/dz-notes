# Gitee 综合指南

## 生成并添加 SSH 公钥

> 来源：[Gitee 帮助中心](https://gitee.com/help/articles/4181)

Gitee 提供了基于SSH协议的Git服务，在使用SSH协议访问仓库之前，需要先配置好账户/仓库的SSH公钥。
你可以按如下命令来生成 sshkey:

```bash
ssh-keygen -t ed25519 -C "xxxxx@xxxxx.com" # Generating public/private ed25519 key pair...
```

> 注意：这里的 xxxxx@xxxxx.com 只是生成的 sshkey 的名称，并不约束或要求具体命名为某个邮箱。
> 现网的大部分教程均讲解的使用邮箱生成，其一开始的初衷仅仅是为了便于辨识所以使用了邮箱。

按照提示完成三次回车，即可生成 ssh key。通过查看 ~/.ssh/id_ed25519.pub 文件内容，获取到你的 public key：

```bash
cat ~/.ssh/id_ed25519.pub
# ssh-ed25519 AAAAB3NzaC1yc2EAAAADAQABAAABAQC6eNtGpNGwstc....
```

复制生成后的 ssh key，通过仓库主页 **「管理」->「部署公钥管理」->「添加部署公钥」**，添加生成的 public key 到仓库中。

添加后，在终端（Terminal）中输入：

```bash
ssh -T git@gitee.com
```

首次使用需要确认并添加主机到本机SSH可信列表。若返回 `Hi XXX! You've successfully authenticated, but Gitee.com does not provide shell access.` 内容，则证明添加成功。

添加成功后，就可以使用SSH协议对仓库进行操作了。

### 仓库公钥和可部署公钥

为了便于用户在多个项目仓库下使用一套公钥，免于重复部署和管理的繁琐，Gitee 推出了「可部署公钥」功能，支持在一个仓库空间下使用当前账户名下/参与的另一个仓库空间的部署公钥，实现公钥共用。

## 搭建 Maven 私有仓库

> 参考：[Gitee Maven 示例](https://gitee.com/fast-template-org/fast-maven-repo/blob/master/use-personal-repo.md)

Gitee可以用来搭建个人的Maven仓库，方便管理和分享自己的Java库。

### 基本步骤

1. 在Gitee上创建一个新的仓库
2. 配置本地Maven设置
3. 将构建好的包发布到Gitee仓库
4. 在其他项目中引用该仓库

### 配置示例

在项目的`pom.xml`中添加仓库配置：

```xml
<repositories>
    <repository>
        <id>gitee-repo</id>
        <url>https://gitee.com/用户名/仓库名/raw/master/</url>
    </repository>
</repositories>

<!-- 如果需要发布到该仓库，还需要添加以下配置 -->
<distributionManagement>
    <repository>
        <id>gitee-repo</id>
        <url>https://gitee.com/用户名/仓库名/raw/master/</url>
    </repository>
</distributionManagement>
```

### 发布包到Gitee仓库

使用Maven命令发布包：

```bash
mvn deploy
```

确保已经在`settings.xml`中配置了对应仓库的认证信息：

```xml
<servers>
    <server>
        <id>gitee-repo</id>
        <username>你的Gitee用户名</username>
        <password>你的Gitee密码</password>
    </server>
</servers>
```

### 在其他项目中使用

在需要使用该库的项目中，添加依赖：

```xml
<dependency>
    <groupId>com.example</groupId>
    <artifactId>your-artifact</artifactId>
    <version>1.0.0</version>
</dependency>
```

##  私人令牌实现免密克隆代码

```text
(1) 获取私人令牌
打开 https://gitee.com/personal_access_tokens
点击“生成新令牌”，获取新令牌，例如：`<GITEE_ACCESS_TOKEN>`

(2) 按照如下格式填写 URL。
https://<user>:<token>@gitee.com/<ower>/<repo>.git
仓库地址为
仓库地址示例：`https://<user>:<token>@gitee.com/<owner>/<repo>.git`

(3) 下载git代码。(推荐)
git clone https://oauth2:<GITEE_ACCESS_TOKEN>@gitee.com/<owner>/<repo>.git
```

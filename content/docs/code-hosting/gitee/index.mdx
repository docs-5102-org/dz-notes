# Gitee

Gitee 是面向国内开发者的代码托管与项目协作平台，支持 Git 仓库、组织协作和项目管理。

## 内容范围

- 仓库创建、克隆和远程地址配置
- SSH 密钥、访问令牌和权限管理
- 分支保护、合并请求和团队协作
- Gitee 与其他远程仓库之间的代码同步

## 文档导航

- [Gitee 综合指南](/docs/code-hosting/gitee/guide)：配置 SSH、公钥、Maven 私有仓库和访问令牌。

使用平台功能时，应以 Gitee 当前的官方文档和权限策略为准。

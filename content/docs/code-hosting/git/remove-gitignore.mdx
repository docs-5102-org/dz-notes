# 从 Git 仓库移除 `.gitignore`

如果 `.gitignore` 已经被提交到仓库，可以停止 Git 对它的跟踪，同时保留本地文件：

```bash
git rm --cached .gitignore
git commit -m "chore: stop tracking .gitignore"
git push
```

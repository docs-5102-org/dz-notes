# Git

Git 是分布式版本控制系统，用于记录代码变化、管理分支并支持多人协作。

## 内容范围

- Git 安装、用户信息和 SSH 密钥配置
- 仓库初始化、提交、回滚和标签管理
- 分支、合并、变基与冲突处理
- Git Crypt、Husky 和 `.gitignore` 管理
- 远程仓库、提交规范和协作流程

## 文档导航

- [检查 SSH 连接](/docs/code-hosting/git/check-ssh)：验证密钥、权限和平台连接状态。
- [配置多个 SSH 密钥](/docs/code-hosting/git/many-ssh-key-config)：为多个 Git 账号配置独立的 SSH 身份。
- [Git Crypt 文件加密](/docs/code-hosting/git/git-crypt)：了解 Git 仓库中的敏感文件加密方式。
- [禁用 Husky](/docs/code-hosting/git/cancel-husky)：临时跳过本地提交钩子检查。
- [从 Git 仓库移除 `.gitignore`](/docs/code-hosting/git/remove-gitignore)：停止跟踪已提交的忽略文件。

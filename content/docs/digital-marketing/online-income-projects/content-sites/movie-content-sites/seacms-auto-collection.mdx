## 分类绑定问题

自动采集时需要绑定本地分类。如果资源库已经在手动采集中完成配置，但自动采集仍无法找到本地分类，可以检查后台 `admin_reslib2.php` 中的绑定参数。以下是原资料提供的调整示例：

```php
// 原始写法
$localId = getBindedLocalId($ressite . '_' . $xmltid); // 入库后本地 id

// 示例调整
$localId = getBindedLocalId('_' . $xmltid); // 入库后本地 id
```

修改前请确认函数调用逻辑、数据库结构和版本差异；不建议直接覆盖生产文件。

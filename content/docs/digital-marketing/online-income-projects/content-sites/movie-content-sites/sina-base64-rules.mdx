# 新浪资讯采集规则 Base64 配置

以下内容说明 SeaCMS 采集规则中 Base64 配置的组织方式。导入前请确认来源、授权范围和目标站点版本，不要将未经授权的内容源用于生产环境。

## 配置示例

```text
# 将采集规则导出为 Base64 文本后，再粘贴到目标站点的规则导入界面。
# 具体字段和编码内容请以当前 SeaCMS 版本的导出结果为准。
BASE64:<在授权环境中粘贴规则导出内容>
```

## 排查步骤

1. 确认规则编码完整，没有被 Markdown、聊天工具或换行处理截断。
2. 检查目标站点的分类映射、字段映射和发布时间格式。
3. 先在测试站点导入少量内容，验证标题、正文、图片和来源字段。
4. 采集失败时保留日志，并核对[海洋 CMS 相关资料](https://www.seacms.net/)。

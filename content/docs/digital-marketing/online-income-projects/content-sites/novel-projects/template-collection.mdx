## 移动端模板方向

- **React Native**：适合需要同时覆盖 iOS 和 Android 的阅读器项目。
- **Flutter**：适合统一 UI 和跨平台交互体验。
- **原生开发**：iOS 使用 Swift，Android 使用 Kotlin，可获得更完整的平台能力。
- **PWA**：适合轻量级、可安装的 Web 阅读应用。

## Web 端模板方向

- 响应式 HTML/CSS/JavaScript 模板：适合内容展示和快速验证。
- Vue、React 等单页应用模板：适合需要搜索、书架、评论和用户中心的产品。
- Jekyll、Hexo、Gatsby、Hugo 等静态站点模板：适合文档、书评和内容专题。
- PHP、Node.js、Django 等动态模板：适合需要后台、数据库和权限管理的站点。

## UI/UX 资源

设计阶段可使用 [Figma](https://www.figma.com/)、[Sketch](https://www.sketch.com/)、[Adobe XD](https://www.adobe.com/products/xd.html) 等工具制作阅读页、书架、分类和会员流程。图标、字体和插图应单独核对授权范围。

## 概述

小米应用市场对应用的隐私合规性检查较为严格，需要特别关注权限申请和隐私政策。本文档总结了上架小米商店时的主要注意事项。

## 主要注意事项

### 1. 隐私合规检测

在上架前进行隐私合规检测是必要的，HBuilderX 提供了相关检测工具。

- [HBuilderX日常踩坑之隐私合规检测](https://blog.csdn.net/tirestay/article/details/127552247)

### 2. 权限申请规范

**重要**：不能在应用未使用相关功能时，提前申请用户权限。

常见被拒原因：
- APP 未使用电话权限功能，但仍申请电话权限
- APP 未使用位置权限功能，但仍申请位置权限
- 其他功能性权限申请不当

解决方案：
- 确保权限申请与实际功能使用相对应
- 仅在用户需要使用该功能时才申请权限
- 参考：[小米应用市场被拒：APP未使用相关功能时，提前申请电话权限](https://ask.dcloud.net.cn/question/209141)

### 3. Android 平台合规协议

需要了解 Android 平台各功能模块的隐私合规协议，确保应用符合要求：

- [Android平台各功能模块隐私合规协议](https://ask.dcloud.net.cn/article/39484)

## 上架前检查清单

- [ ] 进行隐私合规检测
- [ ] 检查所有权限申请是否与功能使用相对应
- [ ] 确保隐私政策完整且可访问
- [ ] 测试所有权限申请的触发场景
- [ ] 准备详细的功能说明文档

## 常见问题

**Q: 权限申请被拒怎么办？**

A: 检查申请的权限是否在应用中确实被使用。如果不需要该权限，需要从代码中移除该权限声明。

**Q: 如何验证权限申请是否合规？**

A: 使用 HBuilderX 的隐私合规检测工具进行检测，按照检测结果进行相应调整。

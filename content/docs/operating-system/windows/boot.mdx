# Windows BIOS Boot 启动参数说明

Windows 系统 BIOS 中，Boot 启动参数说明：

| 序号 | Boot 启动参数 | 说明 |
| --- | --- | --- |
| 1 | Removable devices | 可移动设备（U盘、移动硬盘等） |
| 2 | CD-ROM driver | 光盘启动 / 光驱启动 |
| 3 | Hard driver | 硬盘启动 |
| 4 | Bootable add-in cards | 从外插卡连接的硬盘启动 |
| 5 | Network boot from amd AM79c907A | 网络启动，主要用于无盘工作站，PXE 启动 |

# Windows 10 取消 PIN 码

## 前言

最近安装了一个虚拟机 Windows 10 镜像，安装过程中需要强制使用个人邮箱或微软邮箱，还需要设置 PIN 码，非常烦人。

## 安装成功后如何取消 PIN 码？

1. 打开“设置”，选择“账户”。
2. 在账户设置中，点击左侧的“登录选项”。
3. 在登录选项界面中，找到已设置的 PIN 码，点击其下方的“删除”按钮。
4. 系统会要求输入当前用户的密码进行验证，输入正确后，PIN 码将被删除，之后开机登录时将不再要求输入 PIN 码。

通过以上步骤，用户可以轻松地在 Windows 10 系统中设置或取消 PIN 密码开机登录。

4. 如果点击“Windows Hello PIN”后“删除”按钮是灰色的，此时需要点击“账户信息”，添加一个本地账户信息后再取消 PIN 码。

## 虚拟机设置系统：静态 IP

编辑网络配置文件：

```bash
vi /etc/sysconfig/network-scripts/ifcfg-ens33
```

示例配置：

```text
IPADDR0=192.168.122.108
NETMASK=255.255.255.0
GATEWAY0=192.168.122.1
```

## 常见问题

### # github.com/quic-go/quic-go/http3 ..\..\pkg\mod\github.com\quic-go\quic-go@v0.56.0\http3\client.go:100:31: too  many arguments in call to qpack.NewDecoder         have (func(hf qpack.HeaderField))         want () ..\..\pkg\mod\github.com\quic-go\quic-go@v0.56.0\http3\conn.go:79:38: too many arguments in call to 

当你使用 using gin v1.11.0 版本时，会导致`quic-go` 和 `qpack` 包的版本不匹配。

#### 解决方案

##### 更新依赖版本(推荐)

```bash
# 清理模块缓存[可选]
go clean -modcache

# 更新 gin 和相关依赖
go get -u github.com/quic-go/qpack@v0.5.1 
go get -u github.com/quic-go/quic-go@v0.55.0
# 整理衣领
go mod tidy

go run main.go
```

##### 官方的issue

- https://github.com/quic-go/quic-go/issues/5436
- https://github.com/quic-go/quic-go/issues/5436

##### 原因说明

这个问题的根本原因是:
- `quic-go@v0.56.0` 使用了新版本的 `qpack` 包
- 但你的环境中可能缓存了旧版本的 `qpack`
- 新旧版本的 API 不兼容(`NewDecoder` 和 `DecodeFull` 方法签名变化)

##### 验证修复

修复后运行:
```bash
go run main.go
```

应该能看到:
```
[GIN-debug] Listening and serving HTTP on :8080
```

然后访问 `http://localhost:8080/ping` 应该返回 `{"message":"pong"}`

如果问题依然存在,请分享你的 `go.mod` 文件内容,我可以提供更具体的解决方案。

## 🔥 最受欢迎的 Go 教程仓库

### 1. **Learn Go with Tests**（强烈推荐！）
- 仓库：[quii/learn-go-with-tests-推荐](https://github.com/quii/learn-go-with-tests)
- ⭐ Stars: 22k+
- 通过测试驱动开发（TDD）学习 Go，教你编写健壮、经过良好测试的系统
- 特点：实战导向，边写测试边学 Go

### 2. **LearnGo - 1000+ 实战练习**
- 仓库：[inancgumus/learngo](https://github.com/inancgumus/learngo)
- ⭐ Stars: 18k+
- 包含数千个 Go 示例、练习和测验，通过修复 1000+ 个小程序来学习 Go
- 特点：大量实战代码，做中学

### 3. **Go 官方示例**
- 仓库：[golang/example](https://github.com/golang/example)
- Go 官方的示例项目集合，包括 Hello World、Web 服务器、App Engine 应用等
- 特点：官方出品，最权威

### 4. **Ultimate Go Study Guide**
- 仓库：[hoanhan101/ultimate-go](https://github.com/hoanhan101/ultimate-go)
- ⭐ Stars: 15k+
- Ultimate Go 课程的学习笔记集合，包含带有逐行注释的示例程序
- 特点：详细注释，适合深入理解

### 5. **Go 学习路线图（中文）**
- 仓库：[golang-standards/project-layout](https://github.com/golang-standards/project-layout)
- 特点：Go 项目结构标准

### 6. **TutorialEdge Go 教程合集**
- 仓库：[TutorialEdge/Go](https://github.com/TutorialEdge/Go)
- 包含所有 Go 教程及其源代码和构建状态的主列表，从初学者到高级内容都有

#### **国内第三方**

## 📚 按难度分类

### 🟢 初学者
```
1. golang/example (官方示例)
2. inancgumus/learngo (1000+ 练习)
3. quii/learn-go-with-tests (TDD 方式)
```

### 🟡 进阶
```
1. hoanhan101/ultimate-go (深入理解)
2. TutorialEdge/Go (系统教程)
3. GitHub Topics: go-tutorial
```

### 🔴 高级
```
1. Go 并发编程
2. Go Web 开发
3. Go 微服务架构
```

## 🎯 推荐学习路径

```bash
# 1. 克隆官方示例
git clone https://github.com/golang/example.git

# 2. 克隆 LearnGo 练习
git clone https://github.com/inancgumus/learngo.git

# 3. 克隆 TDD 教程
```

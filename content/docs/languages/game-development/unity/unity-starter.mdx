# Unity 游戏开发框架资源文档

这里整理 Unity 的官方入口、常用框架、工具链与学习路径，适合作为 Unity 方向的资源索引。

- [Unity Hub](https://unity.com/cn/download)
- [Unity 文档中心](https://docs.unity3d.com/Manual/index.html)
- [Unity Learn](https://learn.unity.com/)

- [Photon](https://www.photonengine.com/)

## 学习路径建议

1. 先完成 Unity 官方入门课程与基础示例。
2. 补齐 C# 基础，再进入组件、场景和资源管理。
3. 做 2 到 3 个小型项目后，再选择框架深入。
4. 如果有联机需求，再补网络同步与服务端相关内容。

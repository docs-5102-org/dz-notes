# PS 实操笔记整理

个人使用中记录的 PS 操作技巧汇总，按主题分类，并附相关参考链接。

## 一、选区与抠图

### 1. 魔棒工具抠图不够圆润
魔棒选中的圆形边缘不够平滑时，需要设置**羽化值**让边缘更自然。

- 操作：快捷键 `Shift + F6` 弹出羽化设置窗口，调整数值即可查看效果

参考教程：
- [PS 羽化的用法详解（百度经验）](https://jingyan.baidu.com/)（搜索"PS 羽化 使用方法"可找到多篇图文教程）

### 2. 把图片裁剪/处理成圆形
- [PS 中怎么把图片变成圆形](https://jingyan.baidu.com/article/ad310e80e4bddd5948f49e44.html)

### 3. 快速去除图片中不想要的物体或元素
使用内容识别填充 / 修复画笔等工具，一键去除画面中的多余元素。
- [如何用 Photoshop 快速去除图片中不想要的物体或元素](https://fangx.ai/how-to-remove-objects-in-photoshop/)

## 二、图像尺寸与导出

### 1. 图像大小基本修改
- 菜单路径：`图像 → 图像大小`，修改对应的像素、分辨率
- 菜单路径：`图像 → 模式`，调整图像模式也会影响图像大小的修改方式

### 2. 导出与原图一致大小的图片
- 菜单路径：`文件 → 导出 → 导出为`（快捷键 `Alt + Shift + Ctrl + W`）
- 弹窗中记得勾选**"较小的文件（8位）"**选项，避免体积过大

参考教程：
- 搜索关键词"PS 保存的 png 图片太大"或"PNG 压缩不失真"，可以找到多种压缩方案（如导出为 WebP、使用较小文件选项等）

## 三、文字与排版

### 1. 修改图片中的文字
- [PS 修改图片文字教程（好看视频）](https://haokan.baidu.com/v?pd=wisenatural&vid=11917143959281405369)

### 2. 文字与背景居中对齐
制作条幅、海报时，经常需要让文字在图片中水平/垂直居中。
- [PS 中如何把添加在图片中的文字对齐在中间](https://jingyan.baidu.com/article/7082dc1c6a046ca50b89bd67.html)

### 3. 制作红色条幅（完整流程）
1. 新建文档，颜色模式选择 CMYK
2. 设置前景色为红色，`Alt + Delete` 填充当前图层
3. 使用文字工具在背景上添加文字
4. 设置字体、大小，`Ctrl + T` 调整文字大小并移动到合适位置
5. 保存时另存为 jpg 或 bmp 格式

参考教程：
- [PS 简单制作一个红条幅](https://product.pconline.com.cn/itbk/software/ps/1704/9062704.html)

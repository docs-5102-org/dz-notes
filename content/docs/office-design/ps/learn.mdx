# Photoshop 教程资源汇总

按类型整理的 PS 学习资源，方便按需查阅。

## 一、官方资源

- **Adobe 官方教程（中文）**
  https://helpx.adobe.com/cn/photoshop/tutorials.html
  从基础操作（图像大小、图层、选区、滤镜）到进阶技巧（内容识别、修复工具、发丝级抠图、天空替换、HDR、合成）都有覆盖，质量稳定，紧跟最新版本功能更新。

- **Adobe Photoshop 官方教程 · B站中文字幕搬运版**
  https://www.bilibili.com/video/BV1644y1t7Xp/
  完整搬运自 Adobe 官网教程，132 集，中文字幕，适合系统跟练。

## 二、系统性视频课程（中文，适合从零学起）

- **敬伟 PS 教程**
  http://www.jingweips.cn/
  国内最广泛使用的免费零基础系列课程，3000 分钟实战案例，涵盖修图、磨皮、换脸、证件照、平面设计、插画、网页 UI 等方向。

- **李涛《Photoshop 高手之路》（网易云课堂）**
  偏进阶，重点讲色彩管理、图层、选区、合成与修饰，适合有基础后深入打磨技术细节。

- **优优教程网（PS 板块）**
  国内设计社区优设网旗下的教程站，上千个 PS 教程，按入门/普通/进阶分级，涵盖基础操作、特效设计、插画、UI 设计、合成后期等主题。

- **我要自学网（PS 系列课程）**
  从初级到高级的系统课程，方向较广：图片修改编辑、电商店铺装修、产品精修、图像合成、人像磨皮修图、海报设计、Logo 设计、UI 设计等。

## 三、免费教程网站（分难度路径）

- **Doyoudo**
  93 个免费高质量教程，学习路径清晰：
  - 入门：PS 零基础入门课
  - 初级：黑白照片上色、文字镂空海报、人像油画、表情包制作
  - 中级：双重曝光、波普风人像、通道抠图、阴影立体效果、发光字
  - 高级：3D 卡通文字、文字肖像海报、Low Poly 风格海报、批处理、影像创意

## 四、英文资源

- **Photoshop Essentials**
  https://www.photoshopessentials.com/
  英文免费教程站，写作面向初学者，内容持续更新到 Photoshop 2026 版本，包含近期 AI 新功能相关教程，例如：
  - High Pass 滤镜锐化人像
  - Live Gradients 融合背景
  - 生成式填充（Generative Fill）对齐问题修复
  - 生成式高清放大（Generative Upscale，集成 Topaz Bloom / Gigapixel）
  - Select Subject / 抠图功能升级用法

## 五、书籍推荐

- 《Photoshop CC 从入门到精通》——适合初学者，基础知识循序渐进
- 《Photoshop 设计师之路》——通过实战案例讲解，适合有一定基础者
- 《Photoshop 精粹》——精选实用技巧合集，适合进阶提升

---

### 学习建议

PS 是工具类软件，看教程只是第一步，**多练习实际案例**（抠图、证件照、海报、合成）才是掌握的关键。建议先选一套系统课程（如敬伟 PS 或 Adobe 官方教程）跟着做完基础案例，再按方向（修图 / 平面设计 / UI / 插画）挑专项教程深入。

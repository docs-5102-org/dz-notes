# Excel 快速输入序号

Excel 中快速输入序号的方法很多，可以使用鼠标快捷操作、填充功能和公式。本文介绍几种常见场景：等差序号、等比序号、隔行序号等。

![Excel 序号输入示例](/assets/images/excel/2/unknown_filename.png)

## 1. 鼠标双击快捷输入序号

通过双击鼠标可以快速输入等差为 1 的序列，也就是递增的序号。

在首个单元格输入第一个序号 1，把鼠标移到该单元格右下角，当光标变成实心十字后双击，就会自动填充等差为 1 的序号。

![鼠标双击填充序号](https://pic.rmb.bdstatic.com/bjh/down/17b67c0524e1aa57f961fc506f3e76b7.gif)

## 2. 鼠标下拉拖动填充

使用鼠标下拉也是常见的快捷序号输入方式。

先在第一个单元格输入序号 1，然后选中该单元格，将鼠标放到右下角，按住左键向下拖动至需要的行数。

![鼠标下拉填充序号](https://pic.rmb.bdstatic.com/bjh/down/43675dc631dcd81c3927a1d89c697019.gif)

以上两种方式是 Excel 中最常用的序号输入方式，操作简单且快捷。

## 3. 填充功能的序列设置

如果需要精确设置序列参数，可以使用填充 → 序列功能。

以 WPS 表格为例，点击开始工具栏下方的行和列，选择填充，然后选择序列。

![序列设置入口](/assets/images/excel/2/unknown_filename.1.png)

在序列设置框中，可以选择等差序列、等比序列、日期序列等，并指定步长和值范围。

![序列设置界面](/assets/images/excel/2/unknown_filename.2.png)

例如要生成步长为 3 的序号，直接设置步长值为 3，然后点击确定即可。默认是列序号、等差序列、步长 1，因此只要修改步长值即可。

![步长为 3 的序列填充](https://pic.rmb.bdstatic.com/bjh/down/599f86dac21e864ddbb0d4a30a81fdb5.gif)

如果需要在一行中生成等比序列，可将序列方向改为行，并选择等比序列。

## 4. 等差不为 1 的序号输入

除了填充功能外，也可以通过鼠标手动输入等差不为 1 的序列。

例如要生成等差为 3 的序号，可在第 1、2 个单元格输入 1 和 4，然后选中这两个单元格，将光标移到第 2 个单元格右下角，出现实心十字后向下拖动，即可得到等差为 3 的序号。

![等差为 3 的序号填充](https://pic.rmb.bdstatic.com/bjh/down/cd6326e0ed893c1c68030ea49acf85e7.gif)

## 5. 公式隔行输入序号

当需要每隔一行生成一个序号时，可以使用公式实现。

在首个单元格中输入：

```text
=IF(INT(ROW()/2)=(ROW()/2),ROW()/2,"")
```

该公式的含义是：当 `ROW()/2` 为整数时返回该值，否则返回空字符串。

ROW() 返回当前行号，ROW()/2 对偶数行的结果为整数，INT(ROW()/2) 会向下取整。

![公式隔行输入序号](https://pic.rmb.bdstatic.com/bjh/down/587e73b9c029b2cad971c24e07bc6d39.gif)

## 总结

Excel 序号输入方式很多。常规场景下可优先使用快捷输入和下拉填充；当需要特殊序列或隔行填充时，可使用填充 → 序列或公式。

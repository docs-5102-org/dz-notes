# Stable Diffusion 绘世整合包完整教程

## 前言

绘世整合包是一套面向新手的 Stable Diffusion 集成环境，适合快速开始本地 AI 绘图。

它的优势通常包括：

- 安装门槛低
- 常用插件预集成
- 适合本地离线运行
- 对 Python 和环境配置要求更低

## Stable Diffusion 是什么

Stable Diffusion 是一个文本到图像生成模型，常用于：

- 文生图
- 图生图
- 局部重绘
- 风格迁移
- 角色与场景设计

## 学习建议

1. 先完成整合包安装和启动
2. 熟悉基础参数和提示词写法
3. 学习模型切换、采样器和分辨率
4. 再尝试 ControlNet、LoRA 和工作流优化

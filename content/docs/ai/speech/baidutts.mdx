# 百度云语音合成指南

## 简介

百度云提供文本转语音服务，可将文本内容转换为自然语音，适合用于播报、阅读、客服和内容生成。

## 典型流程

1. 注册百度智能云并开通语音服务
2. 创建应用，获取 `API Key` 和 `Secret Key`
3. 通过鉴权接口获取访问令牌
4. 调用 TTS 接口，将文本转换为音频

## 适用场景

- 网页朗读
- 消息播报
- 客服语音
- 有声内容生成

## 接入建议

- 短文本可直接同步请求
- 长文本建议分段处理
- 注意请求频率和配额限制
- 播放前优先缓存生成结果，避免重复请求

## 常见问题

- 鉴权失败：检查 API Key、Secret Key 和 token 获取逻辑
- 音频为空：检查文本长度、编码和请求参数
- 发音不自然：调整音色、语速和音量参数

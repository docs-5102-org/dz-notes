# Microsoft Azure语音服务常见问题

## 1. 安装 SDK 超时

常见报错：

```text
Timeout trying to fetch resolutions from npm
```

排查方向：

- 检查网络环境是否可访问 npm
- 切换镜像源或代理
- 清理锁文件后重新安装
- 确认 Node 与包管理器版本兼容

## 2. 鉴权失败

排查方向：

- 检查 `speech key` 和 `region`
- 确认环境变量是否正确注入
- 检查请求是否使用了错误区域

## 3. 无法播放音频

排查方向：

- 检查浏览器自动播放限制
- 确认音频流是否成功返回
- 检查编码格式和播放器兼容性

## 4. 中文发音异常

建议：

- 选择明确支持中文的 voice
- 避免一次传入过长文本
- 对标点和换行做预处理

## 5. 生产环境建议

- 使用服务端代理隐藏密钥
- 对请求做限流和缓存
- 为长文本生成加入重试与分段机制

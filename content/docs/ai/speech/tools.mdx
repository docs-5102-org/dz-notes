# 在线语音合成工具汇总

## 选型维度

选择 TTS 工具时，通常重点看下面几项：

- 语音自然度
- 中文支持情况
- 是否支持多音色
- 是否提供 API
- 价格与免费额度
- 是否支持长文本

## 选型建议

- 做产品接入：优先云服务 API
- 做临时配音：优先在线工具
- 做本地离线朗读：优先系统语音引擎或桌面工具

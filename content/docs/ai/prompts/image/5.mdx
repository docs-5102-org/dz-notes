# 暗黑角色与个性风格提示词

适合生成带情绪张力的角色图，例如暗黑朋克、冷感时尚或反叛气质角色。

## 模板

```text
dark fashion portrait, pale skin, rebellious attitude,
moody lighting, textured black outfit, silver accessories,
sharp facial details, cinematic shadows, edgy editorial style,
high contrast, premium character design
```

## 风格扩展

- 朋克：`punk accessories`, `messy hair`, `street background`
- 哥特：`gothic atmosphere`, `deep shadows`, `ornamental details`
- 冷淡时尚：`minimal pose`, `luxury styling`, `studio backdrop`

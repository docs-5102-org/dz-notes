# 动漫风格迁移提示词

适合把真实人物照片、产品照片或场景图改造成动漫插画风格。

## 模板

```text
masterpiece, best quality, anime illustration,
convert the original subject into a clean anime style,
big expressive eyes, soft shading, vivid colors,
well-defined line art, cinematic composition, polished background
```

## 可选增强

- 日系清新：`Makoto Shinkai style lighting`, `bright sky`, `gentle color palette`
- 热血漫画：`dynamic motion lines`, `dramatic contrast`
- Q 版角色：`chibi proportions`, `cute expression`

## 使用建议

1. 如果是图生图，提示词里保留主体身份和服装特征。
2. 风格词不要堆太多，先确定一种主风格。

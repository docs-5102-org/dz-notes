# 习惯养成 App 原型设计

适合让大模型一次性输出产品定位、核心页面、交互流程和视觉方向。

## 提示词模板

```md
你是一名资深移动产品设计师，请为一款“习惯养成”App 输出完整原型方案。

要求：
1. 目标用户：想建立长期习惯的学生与职场人。
2. 输出产品定位、核心价值与差异化卖点。
3. 设计 6 个关键页面：
   - 欢迎页 / 登录页
   - 首页
   - 新建习惯页
   - 习惯详情页
   - 数据统计页
   - 个人中心
4. 每个页面都说明：
   - 页面目标
   - 主要模块
   - 关键交互
   - 需要展示的数据
5. 给出一条完整的用户使用流程。
6. 补充视觉建议：
   - 色彩方向
   - 字体层级
   - 卡片与按钮样式
   - 动效建议

输出格式：
- 产品概览
- 信息架构
- 页面设计
- 用户流程
- 视觉规范建议
```

## 可替换变量

- 行业：健身、学习、专注、睡眠
- 平台：iOS、Android、跨平台
- 风格：极简、活力、治愈、商务

## 使用建议

1. 先生成结构方案，再继续追问单个页面线框。
2. 如果要落地 UI，可追加“输出组件清单”和“状态说明”。

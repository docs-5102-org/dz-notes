## 5. 导出 dex 文件到电脑

```bash
# 夜神模拟器（其他模拟器类似）
# 进入对应模拟器的 adb 命令目录
D:\SoftWare\Nox\bin>nox_adb devices
List of devices attached
127.0.0.1:62001 device

# 夜神模拟器默认连接端口：62001
D:\SoftWare\Nox\bin>adb connect 127.0.0.1:62001
already connected to 127.0.0.1:62001

# 从模拟器中导出对应的 dex 文件
D:\SoftWare\Nox\bin>adb pull /storage/emulated/0/dump d:/tmp
/storage/emulated/0/dump/: 4 files pulled. 0 files skipped. 2.4 MB/s (24182204 bytes in 9.546s)

# 导出下载的 apk 文件
adb pull /storage/emulated/0/Download/mmlu.apk D:/tmp

# PC 与模拟器共享下载目录图片等信息
C:\Users\Administrator\Nox_share
```

## 6. 使用 dex2jar 转换 dex

参考：[dex2jar 仓库](https://github.com/pxb1988/dex2jar)

```bash
# 说明：用于将 dex 文件转换为 jar，建议使用源码编译
# 例如：
d2j-dex2jar.bat D:/tmp/dump/**.dex
dex2jar D:\tmp\dump\classes.dex -> .\classes-dex2jar.jar
dex2jar D:\tmp\dump\classes2.dex -> .\classes2-dex2jar.jar
dex2jar D:\tmp\dump\classes3.dex -> .\classes3-dex2jar.jar
```

//查询音乐的流程

1）根据 音乐榜单接口 https://creator.douyin.com/aweme/v1/creator/data/v2/billboard_detail 获取音乐 billboard\_id=7109372467444975617 其实就是up主的id也就是music\_id

2）https://www.iesdouyin.com/web/api/v2/music/list/aweme/?music_id=7109372467444975617 根据 music\_id=7109372467444975617 获取音乐相关列表接口 第一个是原创

3）https://www.iesdouyin.com/web/api/v2/aweme/iteminfo/?item_ids=7130835407834565921   item\_ids= "aweme\_id" 传递aweme\_id即可获取音乐播放地址

# 抖音平台上传文件的Authorization认证逆向分析

## 简介

抖音平台上传文件包含上传视频、上传图片封面等，由于要实现自动化的上传过程，但是又不想去官方申请api，所以进行Authorization认证逆向拆解计算，而达到自动化的目的。

**抖音上传接口调用的是火山引擎的接口**, 如下：[火山引擎文档](https://www.volcengine.com/docs/4/2915)

```
Authorization: AWS4-HMAC-SHA256 Credential=<VOLCENGINE_ACCESS_KEY_ID>/YYYYMMDD/cn-north-1/vod/aws4_request, SignedHeaders=x-amz-date;x-amz-security-token, Signature=<SIGNATURE>
```    

请求参数如下:

![请求参数截图](/assets/images/network/reverse/unknown_filename.4.png)

可以看出Action值：ApplyImageUpload/ApplyUploadInner 等值，s的值貌似是随机数，比较统一，其余的值都是固定的

可以看出很明显用的是AWS4 SHA256 算法， 计算头部的方法可能是比较重要的，还有如下两个请求头部参数：

```
    X-Amz-Date:20240116T075626Z
    X-Amz-Security-Token: <VOLCENGINE_SESSION_TOKEN>
```    

X-Amz\_Date: 可以看出是一个ios6格式的日期，其余的具体值是怎么算的也是很懵逼呀!!!

## 分析结论

### Authorization 认证结论

`AWS4-HMAC-SHA256 Credential=` : 固定头部

`<VOLCENGINE_ACCESS_KEY_ID>` : accessKeyID

`20240114` : 当前日期

`cn-north-1` : regionName

`vod` : serviceName: //默认“vod”，上传图片是“imagex”，上传视频是“vod”

`/aws4_request` : 固定字符串

`SignedHeaders=x-amz-date;x-amz-security-token` : 固定头部,x-amz-security-token就是SessionToken

`Signature=6a4563beb8d8ae12d816b460029418e1e18311e9a644bf7b383936ee1e34d75` : 签名的重要部分，这个计算非常的繁琐

AccessKeyID、SecretAccessKey、SessionToken 参数是通过 `https://creator.douyin.com/web/api/media/upload/auth/v5/?` 这个接口获取的，每次获取上传地址都有调一次，这里是动态变化的

定位的js：**vender.60eb6efd.js**

## js 实现签名的代码

```js    
    import CryptoJS from 'crypto-js';
    
    function SHA256UseMac(key, message) {
      var hash = CryptoJS.HmacSHA256(message, key);
      return hash;
    }
    
    function getSigningKey(secretAccessKey, dateStamp, regionName, serviceName) {
      var kDate = SHA256UseMac("AWS4" + secretAccessKey, dateStamp);
      var kRegion = SHA256UseMac(kDate, regionName);
      var kService = SHA256UseMac(kRegion, serviceName);
      var kSigning = SHA256UseMac(kService, "aws4_request");
      return kSigning;
    }
    
    // 将时间转化为 ISO字符串
    function toDate(e) {
    return void 0 === e && (e = new Date),
    e.toISOString().replace(/\.\d{3}Z$/, "Z")
    }
    
    //调用 https://creator.douyin.com/web/api/media/upload/auth/v5/ 这个接口返回
    //accessKeyID、secretAccessKey、sessionToken
    
    // 示例使用
    const secretAccessKey = "<VOLCENGINE_SECRET_ACCESS_KEY>"; // 替换为您的 secretAccessKey
    var dateStamp = "20240116T013018Z"; // 替换为实际的日期
    var regionName = "cn-north-1"; // 替换为实际的区域名称
    var serviceName = "vod"; // 替换为实际的服务名称 ，默认“vod”，上传图片是“imagex”，上传视频是“vod”
    
    
    var signingKey = getSigningKey(secretAccessKey, dateStamp, regionName, serviceName);
    
    console.log(signingKey.toString(CryptoJS.enc.Hex));
```

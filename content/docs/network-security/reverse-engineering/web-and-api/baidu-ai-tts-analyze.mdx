Java 的示例：

```java
public static void test(){

String text = "百科，指天文、地理、自然、人文、宗教、信仰、文学等全部学科的知识的总称。";

String vol = "9"; //固定值 音量值

String per = "4100"; //音色id

Long currentMilliseconds = System._currentTimeMillis_() / 1000;

String time = currentMilliseconds.toString(); //毫秒数时间

String once = "fd598a5"; // 计算签名值 必须7位 随机的数字和字母的组合

String s = "%Ej9&lz9\*1R5O\*XCSXvY6E8PlWoZ@haY"; //固定盐值

StringBuilder sb = new StringBuilder()
.append(text).append(vol).append(per).append(time).append(once).append(s);

System._out_.println("sb.toString() = " + sb);
String sign = _md5_(sb.toString());
System._out_.println("sign=" + sign);

StringBuilder url = new StringBuilder("https://baike.baidu.com/wikiui/api/getaudio");

String reqUrl = url.append("?text=").append(text)
.append("&vol=").append(vol)
.append("&per=").append(per)
.append("&time=").append(time)
.append("&once=").append(once)
.append("&sign=").append(sign).toString();

System._out_.println("reqUrl = " + reqUrl);

String res = HttpUtil._get_(reqUrl);

System._out_.println("res = " + res);
```

### Workers与Pages区别

* **TLS加密**
	* Workers：可不加密（不带TLS的理论速度会更快）
	* Pages: 必须加密
* 域名阻断
	* Workers：全阻断（被墙）
	* Pages：电信联通可用，移动需要自定义域名

参考资料：[查看 Workers 的明文脚本及相关帮助文档](https://my.feishu.cn/wiki/Z6U1wrPJSiMcETkl0VmcuWWUnGc?table=tbl2a1fDvMXXJs20&view=veww4yOGZx)。

**注意事项**

* Workers/Pages，尽量不要修改默认的生成的域名，否则可能会出现被阻断的情况

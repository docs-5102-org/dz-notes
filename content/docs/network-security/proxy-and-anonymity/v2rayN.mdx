## 📌 什么是 V2rayN

V2rayN 是 Windows 平台上的图形化代理客户端，基于 V2Ray 核心，支持多种代理协议（如 VMess、VLESS、Trojan、Shadowsocks 等）和传输方式（如 TCP、mKCP、WebSocket 等）。其主要功能是将本地应用程序的网络请求通过代理服务器进行转发，实现更加自由的网络访问和网络加速。

官网：[https://github.com/2dust/v2rayN](https://github.com/2dust/v2rayN)

文档教程：
https://guide.v2fly.org/en_US/basics/vmess.html#client-side

## 🔧 核心选择：Xray vs sing_box

### Xray 特点

- V2Ray 的社区分支/衍生版本，继承了 V2Ray 的核心功能
- 经过长期生产环境验证，稳定性有保障
- 与 v2rayN 的整合度最高
- V2Ray 生态支持完整，功能全面
- **v2rayN 默认使用 Xray**

### sing_box 特点

- 全能的通用代理平台，由 Go 语言编写
- 功能更全面，支持多种代理协议
- 性能更优，资源占用更低
- 配置更灵活简洁
- 社区活跃，更新频繁
- 相对较新，用户基数较小

### 如何选择

如果没有特殊需求，建议使用默认的 **Xray**，这是最稳妥的选择。如果想体验 sing_box，可以在 v2rayN 的核心类型设置中手动切换。

## 🔁 代理模式详解

### 1. 直接代理（全局代理）

**数据流向：**

```
[本地应用程序]
    ↓
[系统代理设置]
    ↓
[V2rayN 客户端]
    ↓
[代理服务器]
    ↓
[目标网站]
```

**特点：**

- 所有网络请求都通过代理服务器转发
- 简单易用，适合需要全局代理的场景
- 缺点：可能导致访问国内网站速度变慢

**适用场景：** 需要完全的全局代理，不关心国内网站速度的情况

---

### 2. PAC 模式（自动代理配置）

**数据流向：**

```
[本地应用程序]
    ↓
[系统代理设置（PAC 文件）]
    ↓
[根据规则选择]
  ↓           ↓
[直连]     [V2rayN 客户端]
              ↓
        [代理服务器]
              ↓
        [目标网站]
```

**特点：**

- 使用 PAC 文件定义哪些网站走代理，哪些直连
- 灵活性高，可根据规则自动分流
- 国内网站走直连，国外网站走代理，速度较为均衡
- 需要维护 PAC 文件，配置相对复杂

**适用场景：** 需要智能分流，既要访问国外网站又要保持国内网站速度的情况

---

### 3. 优选 IP 代理（负载均衡）

**数据流向：**

```
[本地应用程序]
    ↓
[系统代理设置]
    ↓
[V2rayN 客户端]
    ↓
[自动选择最优代理服务器]
    ↓
[优选 IP（如 172.245.64.141）]
    ↓
[代理服务器]
    ↓
[目标网站]
```

**特点：**

- 通过测试多个代理节点的延迟和速度，自动选择最优节点
- 提高连接速度和稳定性
- 需要定期测试和更新节点信息

**适用场景：** 有多个代理节点可用，需要自动负载均衡和优化连接速度的情况

## 🛡️ 伪装域名（Host）配置

### 什么是伪装域名

伪装域名是指在使用 WebSocket（WS）或 TLS 等传输协议时，通过设置 `Host` 字段，将流量伪装成访问正常网站的请求，以提高隐蔽性和抗审查能力。

### 伪装域名的作用

**隐藏真实流量特征**

- 通过伪装成访问常见网站的流量，降低被识别和封锁的风险
- 使流量看起来像是普通的网络访问

**绕过深度包检测（DPI）**

- 使得流量看起来像是正常的 HTTPS 或 WebSocket 请求
- 难以被 DPI 技术识别和阻止

### 配置方法

在 V2rayN 客户端中配置伪装域名时，需要确保客户端和服务器端的配置一致。以下是一个典型的配置示例：

**客户端配置参数：**

|参数|示例值|说明|
|---|---|---|
|地址（Address）|your.domain.com|代理服务器的地址|
|端口（Port）|443|代理服务器监听的端口|
|用户 ID（UUID）|xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx|用于身份验证|
|传输协议（Network）|ws|WebSocket 传输|
|伪装类型（Header type）|none|数据包头部伪装类型|
|伪装域名（Host）|your.domain.com|伪装的目标域名|
|路径（Path）|/path|WebSocket 路径|
|底层传输安全（TLS）|tls|使用 TLS 加密|

## ⚙️ 代理服务器配置

### 方法一：直接代理方式

在直接代理模式下，填写实际的代理服务器地址和端口：

**地址（Address）：** 填写代理服务器的 IP 地址或域名（如 `your.domain.com`）

**端口（Port）：** 填写代理服务器监听的端口号（常见的有 `443` 用于 TLS 加密或其他指定端口）

**适用场景：** 直接连接到代理服务器

### 方法二：优选 IP 反代方式

在使用优选 IP 反向代理（反代）方式时，填写经过筛选的优选 IP 地址和对应的端口：

**地址（Address）：** 填写优选 IP 地址（如 `172.245.64.141`）

**端口（Port）：** 填写与该优选 IP 地址对应的端口号

**适用场景：** 通过优选 IP 提升连接质量和速度

## 📋 配置建议

### 1. 协议选择

在 v2rayN 中，以下协议都默认使用 Xray：

- VMess
- VLESS
- Trojan
- Shadowsocks
- Custom（自定义）项也可以选择使用 Xray 或 sing_box

### 2. 安全性考虑

**对于 WebSocket + TLS 配置：**

- 确保服务器端和客户端的伪装域名（Host）相同
- 使用 TLS 加密保护流量
- 定期检查日志，确保连接正常

### 3. 性能优化

**选择最优代理模式：**

- 如果只访问国外网站：使用直接代理
- 如果需要访问混合内容：使用 PAC 模式或智能分流
- 如果有多个节点：使用优选 IP 模式进行负载均衡

### 4. 故障排除

**连接失败时检查：**

- 确认代理服务器地址和端口填写正确
- 验证伪装域名（Host）配置是否与服务器一致
- 检查 UUID 和其他身份验证信息
- 尝试更换代理模式或代理节点

## 📌 总结

通过合理配置 V2rayN 客户端的代理模式和伪装域名，可以有效提高网络连接的隐蔽性和稳定性。核心要点包括：

1. **核心选择**：默认使用稳定的 Xray，特殊需求可改为 sing_box
2. **模式选择**：根据需求选择全局代理、PAC 模式或优选 IP 模式
3. **配置一致性**：确保客户端与服务器端配置的一致性
4. **安全隐蔽**：使用伪装域名和 TLS 加密提高隐蔽性
5. **定期测试**：定期测试连接速度和稳定性，及时优化配置

这是实现高效、安全、隐蔽代理的关键。

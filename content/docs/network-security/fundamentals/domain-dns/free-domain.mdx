## 使用建议

1. 优先选择有清晰注册、续费和转移政策的平台。
2. 域名注册商与 DNS 托管商分离时，确认名称服务器和 DNSSEC 配置。
3. 不要在公开文档中暴露注册账户、API Token 或域名验证记录。
4. 对免费二级域名设置定期备份和迁移方案，避免平台停服导致业务中断。

# 国外接码平台

国外接码平台通常提供可租赁或购买的国外手机号码，用于接收短信验证码或电话验证码。这类服务可用于国际交易、海外账号注册等场景，但使用前应确认目标网站和服务的条款，避免违反平台规则。

来源参考：[白云居](https://baiyunju.cc/10827)。

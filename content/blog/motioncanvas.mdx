## 什么是 MotionCanvas

MotionCanvas 是一个专为**动效制作 → 视频导出**设计的开源框架，使用 TypeScript + 类 React 语法编写。

**核心优势：**

- 专为"动效导出视频"场景而生
- TypeScript + React 式语法，前端开发者无学习障碍
- 实时预览，所见即所得
- 内置时间轴控制，无需手动处理帧同步
- 直接导出高质量视频，无需额外工具

**适合场景：** 解释性动画、UI 动效演示、教学视频、数据可视化

## 方案对比

| 工具 | 上手难度 | 视频导出 | 3D 支持 | 适合场景 |
|------|----------|----------|---------|----------|
| **MotionCanvas** | ⭐⭐ | ✅ 原生支持 | ❌ | 解释性动画、教学视频 |
| GSAP | ⭐ | ⚠️ 需额外工具 | ❌ | 交互式 Web 动画 |
| Three.js | ⭐⭐⭐⭐ | ⚠️ 需额外工具 | ✅ | 3D 可视化 |
| D3.js | ⭐⭐⭐ | ❌ | ❌ | 数据图表 |
| Manim | ⭐⭐⭐⭐ | ✅ | ❌ | 学术/数学动画（Python） |

**如何选择：**

- 想快速出成果 → **MotionCanvas**（1–2 天上手）
- 已熟悉前端，做交互动画 → **GSAP + 录屏工具**
- 需要 3D 效果 → **Three.js**
- 做数据可视化 → **D3.js**

## 快速开始

### 环境要求

- Node.js 16+
- npm 或 yarn

### 创建项目

```bash
npm init @motion-canvas@latest my-animation
cd my-animation
npm install
npm start
```

执行后，浏览器会自动打开实时预览界面，30 秒内即可看到第一个动画。

### 项目结构

```
my-animation/
├── src/
│   ├── project.ts       # 项目入口
│   └── scenes/
│       └── example.tsx  # 动画场景文件
├── package.json
└── vite.config.ts
```

## 核心概念

### 1. 场景（Scene）

每个动画文件就是一个"场景"，使用 `makeScene2D` 创建：

```typescript
import { makeScene2D } from '@motion-canvas/2d';

export default makeScene2D(function* (view) {
  // 在这里编写动画逻辑
});
```

场景函数是一个**生成器函数**（`function*`），通过 `yield*` 驱动动画逐帧执行。

### 2. 组件（Components）

MotionCanvas 提供了一套内置 2D 组件：

```typescript
import { Circle, Rect, Txt, Line, Img } from '@motion-canvas/2d/lib/components';

// 圆形
const circle = <Circle size={100} fill="#6366f1" />;

// 矩形
const rect = <Rect width={200} height={100} fill="#ec4899" />;

// 文字
const text = <Txt fontSize={48} fill="white">Hello!</Txt>;
```

### 3. 动画（Tweening）

使用 `yield*` + 属性方法来播放动画：

```typescript
// 基础动画：将 size 在 1 秒内变为 200
yield* circle.size(200, 1);

// 带缓动函数
import { easeInOutCubic } from '@motion-canvas/core/lib/tweening';
yield* circle.size(200, 1, easeInOutCubic);
```

### 4. 时间控制（Flow）

```typescript
import { all, sequence, waitFor, chain } from '@motion-canvas/core/lib/flow';

// 同时播放多个动画
yield* all(
  circle.size(200, 1),
  circle.fill('#ec4899', 1),
);

// 顺序播放（带间隔）
yield* sequence(
  0.2,                          // 每个动画间隔 0.2 秒
  circle.size(200, 1),
  rect.rotation(360, 1),
);

// 等待
yield* waitFor(0.5);
```

### 5. 缓动函数（Easing）

```typescript
import {
  easeInOutCubic,   // 最常用，平滑加速减速
  easeOutBounce,    // 弹跳效果
  easeInElastic,    // 弹性拉伸
  linear,           // 匀速
} from '@motion-canvas/core/lib/tweening';

yield* circle.position.x(300, 1, easeOutBounce);
```

## 动画示例

### 示例 1：圆形登场

```typescript
import { makeScene2D } from '@motion-canvas/2d';
import { Circle } from '@motion-canvas/2d/lib/components';
import { easeOutCubic } from '@motion-canvas/core/lib/tweening';

export default makeScene2D(function* (view) {
  const circle = <Circle size={0} fill="#6366f1" />;
  view.add(circle);

  // 从 0 放大到 150，耗时 1 秒
  yield* circle.size(150, 1, easeOutCubic);
});
```

### 示例 2：旋转 + 缩放同步

```typescript
import { makeScene2D } from '@motion-canvas/2d';
import { Rect } from '@motion-canvas/2d/lib/components';
import { all, waitFor } from '@motion-canvas/core/lib/flow';

export default makeScene2D(function* (view) {
  const rect = <Rect size={100} fill="#ec4899" />;
  view.add(rect);

  // 等待 0.5 秒后开始
  yield* waitFor(0.5);

  // 旋转 360° 和放大 1.5 倍同时进行
  yield* all(
    rect.rotation(360, 2),
    rect.scale(1.5, 2),
  );
});
```

### 示例 3：文字逐字出现

```typescript
import { makeScene2D } from '@motion-canvas/2d';
import { Txt } from '@motion-canvas/2d/lib/components';
import { sequence } from '@motion-canvas/core/lib/flow';

export default makeScene2D(function* (view) {
  const letters = 'Hello!'.split('').map((char, i) => (
    <Txt
      fontSize={64}
      fill="white"
      opacity={0}
      position={[i * 50 - 125, 0]}
    >
      {char}
    </Txt>
  ));

  view.add(...letters);

  // 每个字母间隔 0.1 秒依次淡入
  yield* sequence(
    0.1,
    ...letters.map(l => l.opacity(1, 0.4)),
  );
});
```

### 示例 4：完整场景组合

```typescript
import { makeScene2D } from '@motion-canvas/2d';
import { Circle, Txt } from '@motion-canvas/2d/lib/components';
import { all, sequence, waitFor } from '@motion-canvas/core/lib/flow';
import { easeOutCubic, easeInOutCubic } from '@motion-canvas/core/lib/tweening';

export default makeScene2D(function* (view) {
  const title = <Txt fontSize={48} fill="white" opacity={0} y={-150}>MotionCanvas</Txt>;
  const circle = <Circle size={0} fill="#6366f1" />;

  view.add(title, circle);

  // 标题淡入
  yield* title.opacity(1, 0.8, easeOutCubic);

  // 圆形登场
  yield* circle.size(120, 0.8, easeOutCubic);

  // 等待后，同步变色 + 移动
  yield* waitFor(0.5);
  yield* all(
    circle.fill('#ec4899', 1, easeInOutCubic),
    circle.position.x(200, 1, easeInOutCubic),
  );

  // 最后淡出
  yield* waitFor(0.3);
  yield* all(
    title.opacity(0, 0.5),
    circle.size(0, 0.5),
  );
});
```

## 导出视频

### 在编辑器中导出

开发服务器运行时，在浏览器预览界面点击右侧 **Render** 按钮，选择分辨率和帧率即可导出。

### 命令行导出

```bash
# 渲染视频（默认输出到 output/ 目录）
npm run render

# 指定场景
npm run render -- --scene example
```

### 导出配置

在 `src/project.ts` 中配置：

```typescript
import { makeProject } from '@motion-canvas/core';
import example from './scenes/example?scene';

export default makeProject({
  scenes: [example],
  variables: {
    color: '#6366f1',
  },
});
```

**常用导出参数：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--fps` | 帧率 | 60 |
| `--width` | 宽度（px） | 1920 |
| `--height` | 高度（px） | 1080 |
| `--format` | 格式（mp4/webm） | mp4 |

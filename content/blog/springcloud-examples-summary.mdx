### 核心知识点详解

#### 1. Nacos

**服务注册**

```yaml
spring:
  cloud:
    nacos:
      server-addr: 127.0.0.1:8848
```

启动后访问 `http://localhost:8848/nacos/` 查看注册效果。通过修改端口（如 `--server.port=8001`）模拟集群。

**服务发现**

在主启动类添加 `@EnableDiscoveryClient`，支持两种 API：
- `DiscoveryClient`：Spring 标准接口
- `NacosServiceDiscovery`：Nacos 原生接口

**配置中心动态刷新**

| 方式 | 注解/类 | 说明 |
|------|---------|------|
| 手动刷新 | `@Value` + `@RefreshScope` | 需搭配刷新触发 |
| 自动刷新 | `@ConfigurationProperties` | 无感知自动更新 |
| 监听变化 | `NacosConfigManager` | 编程式监听 |

**数据隔离方案**

| 维度 | Nacos 概念 | 作用 |
|------|-----------|------|
| 多套环境 | Namespace（命名空间） | dev / test / prod |
| 多种微服务 | Group | 区分不同服务 |
| 多种配置 | Data-id | 区分不同配置文件 |

**经典面试题：注册中心宕机后远程调用能否成功？**

- 从未调用过 → 立即失败
- 调用过，注册中心宕机 → 因本地有缓存，调用成功
- 调用过，注册中心和目标服务都宕机 → 阻塞后失败（Connection Refused）

#### 2. OpenFeign

**引入依赖**

```xml
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-openfeign</artifactId>
</dependency>
```

主启动类添加 `@EnableFeignClients`。

**进阶配置**

```yaml
spring:
  cloud:
    openfeign:
      client:
        config:
          default:
            connect-timeout: 1000
            read-timeout: 2000
          service-product:
            connect-timeout: 3000
            read-timeout: 5000
            request-interceptors:
              - com.example.XTokenRequestInterceptor
```

**重试机制**

```java
@Bean
public Retryer retryer() {
    // 重试间隔 100ms，最大 1s，最多重试 5 次
    return new Retryer.Default();
}
```

**请求拦截器示例**

```java
public class XTokenRequestInterceptor implements RequestInterceptor {
    @Override
    public void apply(RequestTemplate template) {
        template.header("X-Token", UUID.randomUUID().toString());
    }
}
```

**Fallback（需整合 Sentinel）**

```yaml
feign:
  sentinel:
    enabled: true
```

```java
@FeignClient(value = "service-product", fallback = ProductFeignClientFallback.class)
public interface ProductFeignClient {
    @GetMapping("/product/{id}")
    Product getProductById(@PathVariable("id") Long id);
}
```

#### 3. Sentinel

**整合配置**

```yaml
spring:
  cloud:
    sentinel:
      transport:
        dashboard: localhost:8080
      eager: true
```

**流控规则三要素**

| 维度 | 说明 |
|------|------|
| 阈值类型 | QPS（每秒请求数）或 并发线程数 |
| 流控模式 | 直接 / 关联 / 链路 |
| 流控效果 | 快速失败 / Warm Up / 排队等待 |

**熔断策略**

| 策略 | 触发条件 |
|------|---------|
| 慢调用比例 | 慢请求占比超过阈值 |
| 异常比例 | 异常请求占比超过阈值 |
| 异常数 | 统计窗口内异常数超过阈值 |

**热点参数限流**

```java
@SentinelResource(value = "seckill-order", fallback = "seckillFallback")
public Order seckill(@RequestParam Long userId, @RequestParam Long productId) { ... }
```

可对指定参数索引设置不同限流阈值，支持为特定参数值配置例外（如 VIP 用户不限流、下架商品 QPS=0）。

#### 4. Spring Cloud Gateway

**路由配置**

```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: order-route
          uri: lb://service-order          # lb:// 前缀启用负载均衡
          predicates:
            - Path=/api/order/**
          filters:
            - RewritePath=/api/order/?(?<segment>.*), /$\{segment}
          order: 1
```

**内置断言类型**

| 断言 | 作用 |
|------|------|
| Path | 路径匹配 |
| Header | 请求头匹配 |
| Query | 请求参数匹配 |
| Method | 请求方式匹配 |
| After/Before/Between | 时间范围匹配 |
| Weight | 按权重负载均衡 |

**全局过滤器示例**

```java
@Component
public class RtGlobalFilter implements GlobalFilter, Ordered {
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        long start = System.currentTimeMillis();
        return chain.filter(exchange).doFinally(res -> {
            log.info("耗时：{}ms", System.currentTimeMillis() - start);
        });
    }
    @Override
    public int getOrder() { return 0; }
}
```

**全局跨域配置**

```yaml
spring:
  cloud:
    gateway:
      globalcors:
        cors-configurations:
          '[/**]':
            allowed-origin-patterns: '*'
            allowed-headers: '*'
            allowedMethods: '*'
```

#### 5. Seata（分布式事务）

**三大核心角色**

| 角色 | 名称 | 职责 |
|------|------|------|
| TC | Transaction Coordinator | 维护全局/分支事务状态，驱动提交或回滚 |
| TM | Transaction Manager | 定义全局事务范围，发起/提交/回滚 |
| RM | Resource Manager | 管理分支事务资源，与 TC 交互 |

**接入步骤**

```xml
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-seata</artifactId>
</dependency>
```

在事务发起方方法入口添加 `@GlobalTransactional` 注解，即可开启全局事务，实现跨服务的统一提交与回滚。

## 六、核心组件对比速查

### 注册中心对比

| 特性 | Eureka | Consul | ZooKeeper | Nacos |
|------|--------|--------|-----------|-------|
| 语言 | Java | Go | Java | Java |
| CAP | AP | CP | CP | AP/CP 可切换 |
| 健康检查 | 心跳 | TCP/HTTP/gRPC | Keep Alive | TCP/HTTP |
| 配置中心 | ✗ | ✓ | ✗ | ✓ |
| 维护状态 | 进入维护 | 活跃 | 活跃 | 活跃 |
| 推荐程度 | 旧项目 | 可选 | 旧项目 | **推荐** |

### 服务调用对比

| 特性 | RestTemplate + Ribbon | OpenFeign |
|------|----------------------|-----------|
| 编程风格 | 编程式 | 声明式（注解驱动） |
| 代码量 | 较多 | 少，类似写 Controller |
| 负载均衡 | `@LoadBalanced` 注解 | 内置，自动 |
| 超时控制 | 手动配置 | 配置文件统一管理 |
| 推荐程度 | 基础理解用 | **推荐** |

### 熔断限流对比

| 特性 | Hystrix | Sentinel |
|------|---------|----------|
| 维护状态 | 停止维护 | 活跃 |
| 限流规则 | 简单 | 丰富（QPS/线程/热点/链路）|
| 熔断策略 | 错误率 | 慢调用/异常比例/异常数 |
| 实时监控 | Hystrix Dashboard | Sentinel Dashboard |
| 推荐程度 | 了解即可 | **推荐** |

### 配置中心对比

| 特性 | Spring Cloud Config | Nacos Config |
|------|---------------------|--------------|
| 依赖 | 需要 Git 仓库 | 内置存储，开箱即用 |
| 动态刷新 | 需配合 Bus（MQ）| 原生支持 |
| 命名空间 | 无 | 支持（多环境隔离）|
| 推荐程度 | 旧项目 | **推荐** |

### 关键提示

- 优先学习 **Spring Cloud Alibaba** 生态（Nacos + Sentinel + Seata），这是当前主流
- Eureka / Hystrix 已停止维护，了解原理即可，不必深入
- Gateway 是网关的首选，掌握断言 + 过滤器两大核心机制
- Seata `@GlobalTransactional` 是分布式事务最简便的接入方式
- 开发环境推荐 **JDK 17+**，新版示例已验证 JDK 21 可用

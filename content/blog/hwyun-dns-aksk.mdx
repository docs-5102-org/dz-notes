# 华为云 DNS ak/sk 获取指南（用于证书工具 DNS 验证）

## 背景

弹窗中的"DNS 账户"配置项，是给证书工具做 **DNS自动验证**用的。工具需要自动修改 TXT 记录以完成域名所有权校验，因此这里填写的 AK/SK 必须具备操作华为云"云解析服务（DNS）"的权限。

获取 AK/SK 有两条路径：直接使用主账号（快但权限过大），或新建一个只有 DNS 权限的 IAM 子账号（推荐）。

---

## 方法一：使用主账号（最快，但权限过大）

1. 登录华为云控制台，点击右上角账号名 → **我的凭证**
2. 左侧选择 **访问密钥** 页签 → 点击 **新增访问密钥**
3. 按提示输入登录密码 + 短信/邮箱验证码确认
4. 浏览器会自动下载 `credentials.csv`，第一列为 **Access Key Id（AK）**，第二列为 **Secret Access Key（SK）**

### ⚠️ 注意事项

- **SK 只在创建那一刻可见可下载**，弹窗一关就无法再找回，只能删除旧密钥后重新生成一对
- 华为官方**不建议**直接用账号根用户生成访问密钥；如果一定要用，风险自行承担——根账号的 AK/SK 相当于把整个账号的最高权限都交给了这个第三方面板

---

## 方法二（推荐）：新建只有 DNS 权限的 IAM 子账号

由于这串密钥要贴到第三方系统里，更稳妥的做法是新建一个专用 IAM 用户，只授予 DNS 权限，即使出问题也只影响 DNS。

### 1. 创建用户组

- 控制台右上角 → **统一身份认证（IAM）**
- 创建用户组（例如命名为 `dns-cert`）

### 2. 授权配置

- 对该用户组进行权限配置，在策略列表中搜索并勾选 **DNS FullAccess**
  - 这是华为云为 DNS 服务提供的系统策略，勾选后即可对 DNS 记录进行增删改
- **授权范围务必选择"所有项目"，而非单个区域**
  - DNS 的公网域名权限不支持"全局服务"这种授权范围，必须选择"区域级项目"
  - 若只在某一个区域项目里设置，权限仅对该区域生效；选择"所有项目"才能保证账号下无论切换到哪个区域，密钥都能正常使用

> **补充说明**：如果权限列表里看到的是 **"DNS Administrator"** 这种角色而非策略，注意它依赖 **"Tenant Guest"** 和 **"VPC Administrator"** 两个角色，必须一起授权才能生效，操作上会更麻烦。官方也建议：一个服务如果策略和角色都支持，优先使用策略——因此直接选 **DNS FullAccess** 更省事。

### 3. 创建用户

- 创建用户（例如命名为 `cert-dns-bot`），加入刚创建的用户组
- 访问方式勾选 **"编程访问"** 即可，无需赋予控制台登录权限

### 4. 生成专属 AK/SK

- 用这个新用户登录一次（或由管理员在"用户详情"页代为操作）
- 走 **我的凭证 → 访问密钥 → 新增访问密钥** 流程，获取专属该用户的 AK/SK

---

## 关于 Region 字段

华为云 DNS 的 API 走的是**全局端点** `dns.myhuaweicloud.com`，官方说明建议直接使用默认端点即可，云平台会自动路由到最优节点，只有特殊网络环境才需要指定具体区域的端点。

因此，面板里默认填写的 `cn-north-1` **一般不需要修改**；如果创建后验证失败，可以回头检查这个字段——不同工具接入 SDK 的方式略有差异，个别工具可能确实会用这个值去拼接签名。

---

## 快速对比

| | 方法一：主账号 | 方法二：IAM 子账号 |
|---|---|---|
| 速度 | 快 | 稍慢（需先建用户组和用户） |
| 权限范围 | 账号全部权限 | 仅 DNS 权限 |
| 风险 | 高（第三方面板持有最高权限） | 低（出问题只影响 DNS） |
| 官方建议 | 不推荐 | 推荐 |

# PDF开源桌面工具推荐合计

PDF 是办公中最常用的文档格式之一，除了 Adobe Acrobat 之外，还有很多功能强大、开源免费的 PDF 工具可供选择。以下是一些推荐的 PDF 桌面工具，涵盖了阅读、编辑、合并、拆分等多种功能：

## 工具合集

| **工具** | **平台** | **亮点** | **适合场景** |
|---|---|---|---|
| **Okular** | Win/Linux | KDE 出品，支持标注、表单填写、多格式 | 阅读+轻量标注 |
| **Evince** | Linux/Win | GNOME 出品，轻量简洁，启动快 | 纯阅读 |
| **Sumatra PDF** | Win | 极轻量，开源免费，启动极快 | 纯阅读，性能党首选 |
| **PDF Arranger** | Win/Linux | 专注合并、拆分、旋转、重排页面 | 页面整理 |
| **LibreOffice Draw** | Win/Mac/Linux | 可直接编辑 PDF 内容 | 编辑文字/图形 |
| **PDFsam Basic** | Win/Mac/Linux | 合并、拆分、旋转，界面简单 | 合并拆分 |
| **Stirling PDF** | Win/Mac/Linux（本地部署） | 功能最全，含OCR、压缩、转换、加密等几十种工具 | 全能型，强烈推荐 |

---

**按需求推荐：**

- **只看 PDF** → Sumatra PDF（Windows 最快）
- **标注/批注** → Okular
- **合并/拆分页面** → PDFsam Basic 或 PDF Arranger
- **编辑文字内容** → LibreOffice Draw
- **什么都想要** → **Stirling PDF**（本地部署，无需联网，数据不上云，隐私最安全）

Stirling PDF 特别适合您这类有商业文件需求的场景，所有操作都在本地完成，不用担心报价单等敏感文件泄露。

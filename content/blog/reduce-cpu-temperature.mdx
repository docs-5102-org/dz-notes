# Windows降低CPU温度的方法

## 方法一:通过控制面板(图形界面)

1. **打开电源选项**
   - 右键点击桌面右下角的电池/电源图标 → 选择"电源选项"
   - 或者:`Win + R` 输入 `powercfg.cpl` 回车
2. **进入"更改计划设置"**
   - 找到你当前使用的电源计划(平衡/节能/高性能),点击旁边的"更改计划设置"
3. **进入"更改高级电源设置"**
4. **找到"处理器电源管理"**
   - 展开这一项,会看到两个子选项:
     - **最大处理器状态**(关键设置)
     - 最小处理器状态
5. **修改数值**
   - 双击"最大处理器状态",会看到"接通电源"和"使用电池"两栏
   - 把数值从默认的 100% 改成想要的百分比,比如 **80%、70%** 甚至更低
   - 数值越低,CPU 最高频率被限制得越死,温度降得越明显,但性能损失也越大
6. **点击"应用" → "确定"**保存设置

## 方法二:命令行(适合批处理/脚本场景)

如果想用命令快速设置,可以打开**管理员权限的命令提示符或 PowerShell**,执行:

```powershell
# 设置接通电源时最大处理器状态为 80%
powercfg /setacvalueindex SCHEME_CURRENT SUB_PROCESSOR PROCTHROTTLEMAX 80

# 设置使用电池时最大处理器状态为 80%
powercfg /setdcvalueindex SCHEME_CURRENT SUB_PROCESSOR PROCTHROTTLEMAX 80

# 应用当前电源方案
powercfg /setactive SCHEME_CURRENT
```

## 几点建议

- **建议先调到 80%~90% 测试一下**,降温效果和性能损失之间找个平衡点,不要一下子调太低(比如 50% 以下),否则系统可能会感觉明显卡顿
- 如果你的电脑有**多个电源计划**(平衡、节能等),记得确认你正在改的是当前**激活**的那个计划
- 这个设置对**笔记本**降温帮助比较明显,因为笔记本散热空间小;台式机如果散热没问题,其实不太需要这样限制,更建议先检查风扇/散热膏/灰尘问题
- 如果是游戏或跑分等场景温度高,降低最大处理器状态确实能压温度,但帧率/性能也会同步下降,这是个取舍

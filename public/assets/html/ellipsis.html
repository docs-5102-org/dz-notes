CSS
.single-line { white-space: nowrap; /* 禁止换行 */ overflow: hidden; /* 隐藏溢出 */ text-overflow: ellipsis; /* 显示 … */ width: 100%; /* 必须设定宽度 */ }

多行文本省略
限制显示行数，超出部分用 … 代替
现代浏览器
效果预览 · 限制 3 行
这是一段很长的文本内容，用来演示多行文本省略号的效果。当文本内容超过指定的行数时，多余的内容会被隐藏，并在最后一行的末尾显示省略号。这种方法使用了 -webkit-line-clamp 属性，目前已被所有主流浏览器支持，是最推荐的多行省略实现方案。你可以根据实际需求调整 line-clamp 的数值来控制显示行数。
CSS
.multi-line { display: -webkit-box; /* 弹性盒模型 */ -webkit-box-orient: vertical; /* 垂直方向排列 */ -webkit-line-clamp: 3; /* 最多显示 3 行 */ overflow: hidden; /* 隐藏超出内容 */ }
💡 兼容性：Chrome 6+、Firefox 68+、Safari 9+、Edge 17+ 均已支持，可放心用于生产环境。
